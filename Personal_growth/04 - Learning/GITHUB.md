# Hosting on github

How web-page  works?
- we make a local site and push that into the remote with specific username i.e *username.github.io*

Can I host software on it?
+ if the software only runs on front-end then **yes** but if it needs back-end then **NO**.

Things we need for static webiste:
1. HTML: main page
2. CSS: style
3. JS: interaction

# Github automation


1. Github actions: CI/CD pipelines auto run tests, build, deploy, lint
2. Workflows/Bots: automate labeling issues, closing stale ones, auto merging, notifying 
3. Dependabot: automatically opens PRs to update outdated/vunlnerable dependencies.
