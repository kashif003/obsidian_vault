ChefarCAM:
	#chefarcam

Q. what is the difference between standard attention roll-out and chefarcam?

	attention rollout ignores two important things:
		1. class signal: doesnt matter what the class is?
		2. weights: the weights of MLP and projections heads.

	chefarcam:
		+ tracks relivence instead of raw gradients.
		+ total amount of relevance = sum of relevance flowing into + relevance of that layer.
		+
		solves this by combining the LRP and gradients.
			ensures the explaination is class specific and physically grounded.

		The magnitude is the combination of the attention  weights and the gardients specific to that class.


Ingredients for chefarCAM:
	+ Attention matrix of that layer L. (softamx matrix with Q,K multiplication)
	+ gradient wrt to  class
$$\bar{A} = \text{ReLU}\left( A \odot \nabla A \right)$$

+ sum the result across NXN to get the scaler score for the attention head.
+ take relu as we want to filter out the negative gradients.

	Final Designed Pipeline:
	+ Forward pass
		+ get the activation (QK) values
	+ backward pass
		+ get the respective gradients
	+ make the score
		+ multiply the activation and gradients and apply Relu.
		+ sum up the score to get  the head-wise Scaler

Legrad:
	#legrad

	+ legrad(layerwise gradient)
	+ calculates the gradient in wrt to the attention maps every layer.

Algo:
	+ In forward pass get the activation score.($s_l$) wrt to target class
	+ extract the gradient of each activation score.
	$$\text{Signal}_l = \frac{\partial s_l}{\partial A_l}$$
	+ the gradient is take of the score wrt to the self attention matirx of that layer.
		+ it capture the sensitivity of the feature representation 
+ layer wise aggregation
	+

Pruning PIpeline:
	+ forward pass 
		+ get the activations
	+ backward pass
		+ get the gradients wrt to the attention map of that layer
	+ apply relu
	+ get a singular score for the heads
