**Connection between frontend and backend.**

1. browser runs java script.
2. java script sends HTTP request to backhand usually fetch request.
3. backend receives the request and processes it and send json response.
4. front processes the json response.


**NOTE:** the above methods have huge disadvantages, we are sending one request and one response at a time, if we use *SSE* or *web sockets* we can have the better conversational chat-bot


**Connection with SSE**

1. javascript sends the post request to the backend.
2. the backend receives the question and starts to generate the answer, the connection stays open and the streaming answer from the AI chatbot is kept on.
3. when the  first word is generated, it is sent to frontend which displays it and he response is recorder.

**Connection with web sockets**

*same as **SSE** but the connection is two way*
