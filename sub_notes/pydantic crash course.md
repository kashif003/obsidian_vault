#pydantic


why are we using pydantic:
	+ solves type validation: python can store a variable as int or str so when we are making a request in oder to put correct info in the database with correct format we use pydantic to check the datatype of variable first. e.g age can not be  in bool format.
	+ solves data validation: i.e the value which is valid for the given variable e.g age param can not be less than zero.



How pydantic works?
	1. build a model and define ideal schema of data.
	2. instantiate the model with raw input.
	3. pass the validation model as object.
