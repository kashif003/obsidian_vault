Mapping for sensors and actuators:


- **The gRPC file (`VariablesApi_pb2_grpc.py`)** provides the client methods and functions (such as the stub) that we use to fetch or modify data over the network connection.
    
- **The protocol buffer file (`VariablesApi_pb2.py`)** defines the data blueprints and packages our requests into the correct structures.
    
- **`VariablesApi_pb2_grpc.py`** cannot work without **`VariablesApi_pb2.py`** because it relies on those blueprints to properly serialize and deserialize the messages sent to and from the server.

**Question:**
How can we inject an anomaly by sending three parameters from Python (variable name, value, and duration) to the PLC to force a value for a set time?
**Answer:**
1. **Python Side:** Write a script using the gRPC interface to send the variable name, target anomalous value, and duration to a designated PLC Data Block (DB).
    
      
    
2. **PLC Side (TIA Portal):** Create a PLC program block that reads these three parameters when an `In_Trigger` bit is set to `True`. The PLC will override the target variable with the anomalous value and use an internal timer to hold it for the requested duration before automatically resetting.
