# HOW VERCEL WORKS?

Two components:
1. Serverless Architecture.
2. Edge Network.


## How to host the project?

1. push the code to github repo.
2. Make vercel account.
3. Import the repo from github into vercel account.
4. Configure and build.
5. deploy.

## How to connect to the database?

1. Host the Database on the hosting provider *(e.g MangoDB Atlas)*
2. Get the connection string.
3. configure environment variables.
4. connect inside the code
