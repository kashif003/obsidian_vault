# ⌨️ Hyprland Keybindings Reference

## 🚀 Application & System Shortcuts
| Shortcut | Action |
| :--- | :--- |
| **`SUPER + T`** | Open Terminal (`kitty`) |
| **`SUPER + Q`** | Close active window |
| **`SUPER + C`** | Open Google Chrome |
| **`SUPER + M`** | Open Power / Logout Menu (`wlogout`) |
| **`SUPER + F`** | Toggle floating mode |
| **`SUPER + V`** | Open VS Code (`code`) |
| **`SUPER + E`** | Open File Manager (`thunar`) |
| **`SUPER + R`** | Open Application Menu (`rofi`) |
| **`SUPER + P`** | Pseudo-tile window |
| **`SUPER + J`** | Toggle split layout |

## 🪟 Window Navigation & Workspaces
| Shortcut | Action |
| :--- | :--- |
| **`SUPER + Arrow Keys`** | Move focus (Left, Right, Up, Down) |
| **`SUPER + [0–9]`** | Switch to workspace 0 through 9 |
| **`SUPER + SHIFT + [0–9]`** | Move active window to workspace 0 through 9 |
| **`SUPER + S`** | Toggle special workspace (scratchpad) |
| **`SUPER + SHIFT + S`** | Move active window to special workspace |
| **`SUPER + Mouse Scroll`** | Cycle through workspaces |

## 🖱️ Mouse Controls
| Shortcut | Action |
| :--- | :--- |
| **`SUPER + Left Click & Drag`** | Move window |
| **`SUPER + Right Click & Drag`** | Resize window |

## 🔊 Media & Function Keys
| Shortcut | Action |
| :--- | :--- |
| **`Volume Up / Down / Mute`** | Adjust or toggle system audio |
| **`Mic Mute`** | Toggle microphone mute |
| **`Brightness Up / Down`** | Adjust screen brightness |
| **`Media Keys`** | Play, pause, next, or previous track |
